# 難しいタスクのテスト用プロンプト

`uv run scripts/chat.py`（難しいものは `--thinking` 付き）に貼り付けて使う。
各問の正解は計算・実行で確認済み。思考モード OFF / ON で比べると差が見やすい。

---

## 1. 数え上げ（数学）

```
1 から 1000 までの整数のうち、各桁の数字の和がちょうど 13 になるものはいくつありますか？
最後に「答え: <数>」の形で答えてください。
```

- 正解: **75**
- ポイント: 総当たりできないので場合分けが必要。思考モード OFF だと間違えやすい。

## 2. ひっかけ問題（論理）

```
花子には兄が 3 人います。兄たちはそれぞれ妹が 2 人います。花子には姉妹が何人いますか？
```

- 正解: **1 人**（花子ともう 1 人の妹で、妹は計 2 人）
- ポイント: 「2 人」「6 人」と答えたら失敗。

## 3. 文字の数え上げ（トークン化の弱点）

```
「とうきょうとっきょきょかきょく」の中に「きょ」は何回出てきますか？
出てくる位置もすべて示してください。
```

- 正解: **4 回**（とう**きょ**う / とっ**きょ** / **きょ**か / **きょ**く）
- ポイント: LLM は文字単位で数えるのが苦手。

## 4. 日付計算（多段の推論）

```
2026 年 10 月 21 日の 100 日後は何年何月何日で、何曜日ですか？計算過程も示してください。
```

- 正解: **2027 年 1 月 29 日（金曜日）**
- ポイント: 月ごとの日数の足し算と曜日の計算の両方が必要。

## 5. 画像の精密な比較（視覚）

```
/image sample.png 3 つの図形を面積が大きい順に並べてください。根拠となる寸法の見積もりも示してください。
```

- 正解: **青い四角 > 赤い円 > 緑の三角**
  - 四角: 80×80 = 6400 px、円: 半径 45 で約 6349 px、三角: 約 3808 px
- ポイント: 四角と円の差は 1% 未満。見た目では円のほうが大きく見えやすい。

## 6. 制約の多い文章作成（指示追従）

```
秋についての文章を書いてください。ただし次の条件をすべて守ること。
- ちょうど 3 文
- 各文は 20 文字以内
- 「の」を一度も使わない
- 最後の文は疑問文
```

- 判定: 条件を 1 つずつ目で確認する。「の」を使わない条件が最も破られやすい。

## 7. 厳密な JSON 出力（エージェント向け）

```
次の文から予定を抽出し、JSON だけを出力してください（説明文やコードブロック記号は不要）。
形式: {"events": [{"title": 文字列, "date": "YYYY-MM-DD", "start": "HH:MM", "participants": [文字列]}]}

「来週の火曜（2026-10-27）の 15 時から田中さんと佐藤さんとで設計レビュー。その翌日の朝 9 時半に佐藤さんと 1on1。」
```

- 正解:
  - 設計レビュー: 2026-10-27, 15:00, [田中, 佐藤]
  - 1on1: 2026-10-28, 09:30, [佐藤]
- ポイント: 「翌日」の日付計算と、JSON 以外を出力しないこと。LangGraph でツール呼び出しを使うときに重要になる力。

## 8. コードのバグ発見（コーディング）

````
次の Python 関数のバグをすべて指摘し、修正版を示してください。

```python
def moving_average(xs, k):
    """長さ k の移動平均のリストを返す"""
    result = []
    s = sum(xs[:k])
    for i in range(k, len(xs)):
        result.append(s / k)
        s += xs[i] - xs[i - k]
    return result
```
````

- 正解: 最後の窓の平均が追加されない（ループ後に `result.append(s / k)` が必要）。
  - 例: `moving_average([1, 2, 3, 4], 2)` → 正しくは `[1.5, 2.5, 3.5]`、現状は `[1.5, 2.5]`
  - 追加の指摘として `k <= 0` や `k > len(xs)` の扱いに触れれば加点。
